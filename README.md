# AWGV in 7 Tagen

Lernplattform zum **Allgemeinen Weggrößenverfahren** (Baustatik, htw saar) – als iPad-App installierbar.

**Installieren auf dem iPad:** Seite in Safari öffnen → Teilen-Symbol → „Zum Home-Bildschirm“.
Danach startet die App im Vollbild und funktioniert auch offline.

Update-Hinweis: Bei inhaltlichen Änderungen `VERSION` in `sw.js` erhöhen.
